# Vitapp — web

Next.js 16 (App Router, Turbopack) + Supabase + Anthropic API. Ver `CLAUDE.md` en la raíz del repo para el estado del proyecto.

```bash
npm run dev      # http://localhost:3000
npm run build
npm run lint
```

Variables de entorno: ver `.env.example` en la raíz del repo (`NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `ANTHROPIC_API_KEY`).
